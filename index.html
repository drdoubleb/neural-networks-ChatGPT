A LECTURE IN MINIATURE

Open the black box.

A suggested 10–15 minute live demonstration for pathology residents.

  1. Start with a question, not a model.

    “Is this contour irregular?” is much narrower than “Is this cancer?” Look at the dataset; discuss what is missing from a real slide.

  2. Build the smallest useful neuron.

    Use the One neuron preset. Four measurements enter, each multiplied by a weight. Add a bias; a sigmoid turns the score into a number between 0 and 1.

  3. Let it be wrong. Then show one update.

    Compare its output with the known label: regular = 0, irregular = 1. Cross-entropy penalizes errors, particularly confident errors. Backpropagation gives a gradient; gradient descent changes the weights.

  4. Watch it learn, then remove our help.

    Start training. Inspect the weights and curve. Switch to Learn from pixels: now the 256 image intensities go in. Eight hidden tanh neurons can combine patterns nonlinearly. This resets training.

  5. Test what it learned.

    Run the 20 held-out examples. Inspect mistakes and the confusion matrix. Move the decision threshold: sensitivity and specificity change even though the weights do not.

  6. Ask what could go wrong.

    Try Less data, a different seed or a very large learning rate. Inspect Influence; shift a nucleus. A successful toy model may still rely on shortcuts. Real performance needs representative, independent patient-level data.

The essential distinctions

  • One neuron: logistic regression, with one learned affine layer plus sigmoid. The input layer is not counted.
  • Hidden layer: a small fully connected network, not a convolutional network. Hidden units use tanh; the output uses sigmoid.
  • Shape mode: humans designed four measurements. The model only learns their combination. A single neuron can work well because those measurements already encode useful information.
  • Pixel mode: the model receives 256 intensities. No label, sample ID, generator parameters or contour coordinates enter the network.
  • Influence: a measured response to patch removal. It is neither an attention mechanism nor a guarantee that the model reasons like a pathologist.
  • 20 test cases: a teaching exercise, not a clinical validation. Repeatedly consulting them to tune the model means they are no longer an untouched final test.
